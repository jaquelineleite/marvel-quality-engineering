# Marvel Quality Engineering Challenge

Prova prática para a posição de Analista de Qualidade Pleno — Engenharia de Plataforma / SDLC.

## Contexto

O desafio contempla validações de API e frontend, com foco em estratégia de testes baseada em risco, automação sustentável, qualidade contínua e boas práticas de versionamento.

A API Marvel Rivals originalmente indicada no desafio apresentou indisponibilidade HTTP 502.

Conforme orientação posterior recebida dos avaliadores, a camada de API será implementada utilizando a Marvel Developer API indicada no segundo comunicado.

## Alvos do desafio

### API

Marvel Developer API

https://api.marvelapp.com/graphql/

### Frontend

Marvel Rivals Heroes

https://www.marvelrivals.com/heroes/index.html

## Estratégia

A solução será construída incrementalmente, priorizando:

- análise de riscos;
- estratégia de testes em camadas;
- automação de API;
- automação frontend;
- testes exploratórios;
- validação de contrato;
- performance;
- CI/CD;
- Quality Gates;
- documentação;
- evidências.

> A documentação será expandida conforme a evolução da implementação.
